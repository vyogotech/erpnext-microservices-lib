# Frappe/ERPNext dependencies a headless microservice never loads.
#
# SINGLE SOURCE OF TRUTH. Read by:
#   scripts/resolve_frappe_deps.py  -- to filter them out at build time
#   scripts/check_pruned_deps.py    -- to verify nothing else broke
#
# Frappe's dependency list assumes a full Desk install: PDF printing, Excel
# import, 2FA QR codes, full-text search, an interactive console, Google
# integrations. See docs/dependency-slimming.md for how this list was measured
# and for the packages deliberately NOT here.
#
# Names are matched case-insensitively with - and _ normalised.
#
# One blank-line-separated group per capability.
#
# An entry that is not present upstream is a harmless no-op. As of frappe
# v16.28.0 that is true of `posthog` and `Faker`: frappe's pyproject.toml
# declares them but the pinned build does not install them. They stay listed so
# a future version that does ship them is covered. Run resolve_frappe_deps.py to
# see which entries currently match something.
